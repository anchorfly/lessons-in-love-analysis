*********************************
Progress & Guidance Mod v0.60.0
*********************************

- Install by copying the files into your LiL install folder.

*********************************
Progress Screen
*********************************

IMPORTANT: This is distinct from the "Progress" button on the botton of the screen in the base game

* Adds a single screen showing all stats and event progress (accessible via "Progress" on the menu sidebar)
* Girls are added to the screen in accordance with story progress
* An ! indicator appears next the names of girls with events available
* Clicking on a girl's name (or on "Main" or "Happy") on this screen will take you to the corresponding tracker

*********************************
Guide Mod
*********************************

* The Guide Mod adds a column of guidance to modified versions of the event trackers
* A single line of guidance is provided for each incomplete event that a player is reasonably close to seeing
* Guidance is updated as you fulfill requirements
* Guidance for Happy Events is not provided until a player has entered their event track
* A compilation of all available guidanec is provided on the Hint screen

*********************************
Keyboard Shortcuts
*********************************

	P : Progress screen
	M : Main Events tracker
    N : Hint screen
	G : One of the girl's trackers (Sana by default, otherwise your last visited girl)
	O : Mod Options screen
    T : Toggles whether completed events are shown on trackers
	U : Refreshes the progress/hint screens
    C : Toggles whether icons for girls with no uncompleted events are shown on trackers

* These shortcuts will only become active after you've visited the Progress screen for the first time.
  If they stop working for whatever reason, revisiting the Progress screen will reactivate them.
  You may need to click on "Return" in the lower left corner rather than exiting via ESC at least once.
* Pressing "P", "G", or "N" while on the progress/girls/hint screen will return you to the game, provided
  you used those shortcuts to open the screen in the first place.

*********************************
How the Hints Work:
*********************************

The general idea behind the guidance is to avoid overwhelming the player with two many hints.

1.	If no guidance is offered for an event, it either means that that event is too far away to worry about
	or it will happen automatically.
2.	If the guidance says "progress needed", it means that you need to see at least one event of each of the
	listed types to unlock the event.
3.	A red (!) at the end of the guidance indicates either:
	1. if it's a lust event (pink text), the event is time sensitive and you should prioritize it
	2. if it's a normal event (black text), the event involves an important choice. Make a save beforehand.
	Clicking on the red (!) will take you to a screen with more specifics
