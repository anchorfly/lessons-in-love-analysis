AUTO VN MOD
for LessonsInLove-0.60.0-pc


Install by copying and replace the files into your LiL folder.
Toggle On/Off in the Settings game menu.



Features:

- If ON, events are automatically started in the order they are available.
If there are not enough points for an event, they will be added.
If there are no events available, several days will be skipped automatically.
The order is adjusted so that there are no missed events or h-scenes.

- If ON, adds warnings for important choices in the game.
Warning is shown at the beginning of the event. If you don't know what to choose, look at the History, was there AUTO MOD WARNING or no.
Except events where the choice affects immediately, there are unnecessary to hints.

- The mod does not make the choice for you.
If you independently make chose like no sex with mommies or be good uncle, scenes corresponding to your choice will be skipped.

- There are no auto-pass for reset events.
Resets are events that you have to pass yourself. Praise be.

- You can turn it OFF at any time and play a normal game, and then turn ON at any time.

- Does not spoil saves. You can open the save in the standard game without mod.
Almost. The mod changes variables and makes transitions between events. If you make a save at such a point, you can not be able to open this save in the standard game.
Just make a save a little earlier or a little later.

- There should be no conflicts when updating the game.
You can update the game without updating or deleting the mod.

- You can use the mod with the game version higher than the mod version.
The mod will work until the event known to it, and then will turn off.
I.e. the mod can be used even if the author of the mod (me) forgets about it. Or until Selebus rewrites the game again.

- There are no conflicts with the Hint mod.
Conflicts with other mods have not been checked.

- The mod changes variables and checks conditions between events.
If the mod was OFF and you turned it ON in the middle of event, it will not affect on this event.
If this is important, then rewind to the previous event and turn ON the mod.



Additional features:

- Added menu image selection - available all old menu images from 0.24 up to the current version
- Changed Event tracker menu - the old menu is used up to chapter 3, and a new one from chapter 4
- Changed icons in the Main/Side girls menu - old character's icons are used up to chapter 3, and a new one from chapter 4
- In the Main/Side girls menu - characters that are not yet available are hidden
- In Progress menu - characters that are not yet available are hidden
- The Progress menu counts the number of events in the current chapter
- The Happy scenes tracker displays the events in the current chapter
- Changed images in repeatable dorms events - the character's appearance corresponds to the stage of the game



Known problems:

Problem:  Please note that the mod changes variables and checks conditions before the events start, but sometimes before the chain of events, such as dormwars.
If the mod was OFF and you turned it ON in the middle of event, it will not affect on this event and the h-event may be missed.

Solution: Turn ON the mod before large chain begins, i.e. beach/dormwars.

Problem: After rolling back, the mod did not set the necessary variables and got missing events.
The reason is in the mechanics of the mod - the mod replaces some labels, sets the variables, then calls the real label. Whith rolling back the variables are not re-set.

Solution: Load from an earlier save. After loading, the mod will work correctly.

Problem: You turned the mod ON and nothing happens.

Solution: Perform any action. The "generic" event will trigger. And the next, the mod will launch plot event.

Problem: Game updates sometimes break saves, so it is recommended to save between events (i.e. after school menu or weekend menu). However, the mod disables such choice points, so there may be (or may be not) problem with saves after updating the game.

Solution: Before update the game, turn the mod OFF, reach the end of the event, make a save.
Usually it is not necessary. Only if you have problems with saves when updating the game.
