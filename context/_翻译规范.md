> 本文件由翻译工作过程沉淀,后续所有批次必须遵守,保证全书风格统一。

## 流水线(必读)

```bash
cd context
node _pipeline.js gen "Ami Arakawa"   # 为某分类生成骨架(events/{label}.json,en 自动提取,zh 全空)
node _pipeline.js gen all             # 全量生成
node _pipeline.js pending "分类名"     # 列出该分类未翻的 label
# 翻译:读 events/{label}.json → 写 events/_zh/{label}.json = {"title_zh":"...","zh":[与lines等长的数组]}
node _pipeline.js inject {label}      # 注入并删中间文件(校验长度)
node _pipeline.js verify {label}|all  # en 与 guide.html 源文逐字符比对
node _pipeline.js stats               # 全局进度
```
- 英文标题→中文标题对照源:`_titles.json` 可用 `node -e` 重新导出(见 git 历史)。
- [c] 代码行(label/jump/$ 等)不收;`.l` 对话行全收,含选项。

## 铁律

1. **人名一律保留原文**(用户指示):Ami、Maya、Ayane、Sekai、Chika、Yumi、Makoto、Uta、Osako、Kaori、Sara、Haruka、Futaba、Kumon-mi(地名)、Sensei、Selebus 等,绝不翻译。
2. **`lines[].en` 逐字符锚定**:由脚本提取保证;译文只写 zh。
3. **变量占位符原样保留**:`[niece]` `[uncle]` `[teenage]` `[high_school]` `[school]` `[amimaster]` `[ami_love]` `[ami_lust]` `[raping]` `[incest]` 等。
4. **行首说话人残留 `": "` 原样保留**,zh 同样以 `": "` 开头(与 en 对齐)。
5. 省略号行(`...`/`......`/`.........`)与乱码彩蛋行(`////????`、hex 串)原样保留,不译。
6. 有省略号重复句是文学母题,必须全书统一:
   - `I want to feel it again.` = 「我想再感受一次。」
   - `The world breaks.` = 「世界崩坏了。」
   - 好感提示 `Ami's affection has increased to [ami_love]!` = 「Ami 的好感度提升到了 [ami_love]!」;lust 版=「Ami 的欲望提升到了 [ami_lust]!」
