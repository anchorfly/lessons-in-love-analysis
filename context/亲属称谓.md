# 亲属称谓术语表（权威版）

> 来源：从 `游戏文本/**/*.rpy` 逐条考证（2026-10-04）。
> 用途：翻译时确定亲属词的中文译名，避免「姐姐/妹妹」「叔叔/舅舅」混用。

## 🔴 铁律

1. **`uncle` → 「叔叔」**（指 Sensei 时）。Ami 是 Sensei **哥哥** Nozomu 的女儿 ⇒ **父系**。
   **绝不译「舅舅」**。对应 `niece` → **「侄女」**。
2. **长幼必须按视角判断**，不能见 `sister` 就译「姐姐」。
   判断依据：谁在说、对谁说。同一句 `your sister`，
   Sensei 对 **Noriko** 说 = Niki（**姐姐**）；Sensei 对 **Niki** 说 = Noriko（**妹妹**）。
3. `sister-in-law` → **「嫂子」**（Sekai 是 Sensei 哥哥的妻子），不要直译「小姨子」。
