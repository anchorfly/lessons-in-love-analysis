# Yumi 事件线全析（逐事件深读版）

> 源文件：`YumiEvents.rpy` ｜ digest：`_digest_Yumi.txt`（5312 行，覆盖源行 [1]–[10203]）｜ 共 33 个 label
> 定位一句话：**已知觉醒者**——街头问题少女、"Rooftop Apocalypse Squad" 关联成员，全游戏元叙事密度最高的角色之一："我知道这游戏怎么运作"、脑内寄宿的 pareidolia、被 Yuki"制造"的身世之谜、母亲癌症线，以及 chap4 春季十连中几乎每章一次的旁白人格入侵。

## 一、角色基本盘

- **出身与关系网**：街头少女，与 Sensei 初始敌对（[865] y: "We don't like each other, remember?"）；与 Yuki 有深厚羁绊（Yuki 线揭示 "I remember how Yumi was made"），chap4spring8 揭示 Yuki 确诊肺癌且 Yumi 是其女儿级存在。
- **性格底色**：粗口密集、攻击性外皮包裹深度自毁倾向（[1066] "make myself throw up *again* for even remembering it"）；对被遗弃极度恐惧（[8005] "Don't leave me, please"）。
- **元认知层级**：正面宣称懂游戏规则（[2518]）、自指"Patreon friendly version of the game"（[309]）、能直呼寄生实体之名 Pareidolia 并向元层道具许愿（dormwarssix9）。
- **核心情感弧**：敌对 → 相互拯救（桥上救下自杀倾向的 Sensei）→ Chika 因她生妒 → 母亲癌症 → 首个真实之吻与"harem 宣告"。她是少数拥有**完整跨时间线记忆闪回**的角色（beachfive13 detention 记忆）。

## 二、love 线逐事件脉络

### 街道链与电话链（前期）

- **`streets`**[1]：Yumi 初登场。街头相遇，双方以互相嘲讽开场，确立"互不喜欢"的对抗性基调；本 label 主要完成人物声线与街头生态（便利店、巷子）的场景铺设。
- **`callyumimorning`**[37] / **`callyumiafternoon`**[57] / **`callyuminight`**[77]：三段时段变体的电话事件，按好感度触发；内容为短对话碎片，用于维持联系感，Yumi 接电话的态度随进度从"你打来干嘛"转为默许。
- **`yumigennight`**[97] / **`yuminoongen2`**[164]：通用夜间/午后小事件，填充日常质感；Yumi 的街头生存细节（蹭吃蹭喝、躲管理人）在此类事件中零散呈现。
- **`firsttimestreets`**[198]：第一次正式街道事件。Sensei 撞见 Yumi 与街头同伙的互动，首次看到她在"自己的地盘"上的支配姿态；两人不欢而散但留下继续接触的钩子。
- **`streets2to4`**[487]：街道链早期合集。**关键台词**：[308–309] y: "...punching old people is a character trait I have in the **Patreon friendly version of the game**."——角色以自身为"受版本审查的内容"自指，第四面墙首次在 Yumi 线开裂。
- **`streets5`**[509]：对抗开始松动的小事件，Yumi 首次表现出对 Sensei 出现在她领地一事的**习惯化**而非驱逐。
- **`streets10`**[802]：敌对关系的自我确认与裂痕并存。[865] "We don't like each other, remember?"；随后 Sensei 视角出现循环母题：[986–988] "I remember kissing/hugging Yumi but...such a hazy memory it almost doesn't feel real"——**上一轮循环的亲密残像**。[1066] Yumi 自述会"为了记得它而再吐一次"，暴露创伤性记忆。
- **`streets15`**[1101]：关系推进档。共同经历街头麻烦后 Yumi 首次主动分食/分享，敌对框架内部长出同盟雏形。
- **`streets20`**[1495]：中期事件。Yumi 开始向 Sensei 泄露私人信息（住处不稳定、对学校系统的蔑视），信任单向先行。
- **`streets25`**[1796]：**身体张力节点**：[1961] y: "...you're the one pinning *me* to the wall"——墙边推压的攻守反转台词，lust 线张力的主要载体；同时 Yumi 对 Sensei 的称呼从侮辱滑向昵称。
- **`streents30`→`streets30`**[2248]：**觉醒宣言节点**：[2517–2518] y: "They'll just think I'm trying to damage your reputation or some shit. **I know how this game works.**"——表面谈流言机制，实为角色对"游戏"（galgame 社会系统/本作本身）的双重宣示；本档还铺垫了她与其他觉醒角色的信息互通可能。
- **`yumicallnight35`**[2634]：深夜来电。Yumi 失眠致电，语气罕见地软；暗示其夜间独处时的脆弱面，为 special 链做情绪铺垫。
- **`yumispecial40`**[3160]：special 链开篇。脱离街头场景的私密相处，Yumi 展示对 Sensei 的占有式关注；叙事节奏开始混入异常旁白。
- **`yumispecial40p2`**[3439]：special 后半。**Maya 裂痕旁白**落在本档末端：[3603–3604] N: "Even that part of Maya's personality has been beginning to show cracks as of late."——叙述者直接宣告 Maya 权威结构正在崩解（与 Tsuneyo/Makoto 线互证）。
- **`streets40`**[3812]：街道链终档。Yumi 与 Sensei 的关系已被周围视为既成事实；街头部分收束，叙事重心移交 special/slumber/spring。

### 特殊·留宿链（中期）

## 三、lust 线概貌

Yumi 无独立命名 lust 事件；性张力全部内嵌于 love 链的三种形态：

1. **对抗性身体接触**：墙边推压的攻守反转（[1961]）——她的欲望语言就是打架语言；
2. **glitch 欲望实体**：[6448] 故事文本爆出露骨欲望宣言，把"想上坏女孩"的猎奇幻想做成故障字幕，欲望被呈现为系统入侵而非角色台词；
3. **交易化亲密**：爱情旅馆过夜、$10,000 入府、harem "indoctrinated" 结算——每次身体/情感进展都配有一个**系统层记账动作**， lust 被 UI 化。

## 四、与主线 / 元叙事咬合点

1. **觉醒者网络节点**："I know how this game works"[2518] + "Patreon friendly version"[309]，使 Yumi 与 Makoto/Ayane 同列高元认知层；dormwarssix9 中她能**直呼 Pareidolia 之名**并向 Wise Turtle 许愿放逐它——觉醒不是旁观，而是与寄生实体的长期同居。
2. **Maya 体系崩塌的见证人**：[3603–3604] 叙述者宣告 Maya 人格开裂；spring4 确认 **Maya 已死**（"Ponytail...right?"[7427]）。Yumi 线是 Maya 从"权威"到"死者"过渡的目击现场。
3. **世界屏障**：[5084–5085] 巨大墙进入 Yumi 台词，与 Touka 隔离政策、Ayane 未来线拆墙构成同一物理设定的三方印证。
4. **旁白人格的众声喧哗**：Yumi 线先后出现小写 N、斜体 N、JOSEPH[6994]、q（伪母亲之声）、dem 合唱、vpa 广播、sev 节目主持、Migi/Hidari 黑板神——**单一叙述者假设在她这条线上彻底破产**，旁白本身成为多神教万神殿。
5. **Untitled Children's Show 装置**：从 spring1 的"恶魔妖精"提问[5918–5984]到 spring10 的 Pareidolia 上节目与 "Code of Joy"[10166]，这档节目是连接童真表层与深渊设定的专用通道，且明确"it never changes. not even with a key."[10188–10189]——**连 meta 钥匙也改写不了它**。
6. **UI 讽刺系统**：假好感度增减（[7312–7313]）、RPG 结算（[9387–9391]）、harem 认领（[10093]）——Yumi 的每次情感进展都被系统即时"入账"，恋爱模拟外壳与真实创伤持续互相拆台。
