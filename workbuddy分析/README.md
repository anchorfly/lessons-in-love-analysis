# Lessons in Love 分析文档

本目录为对 Ren'Py 视觉小说《Lessons in Love》反编译脚本的剧情分析产出，包含全部深度阅读与索引。

## 分析方法
- 使用自研 `digest_events.py` 脚本从 71 份 `.rpy` 源脚本抽取事件流摘要，保留标题行头与源行号。
- 摘要产出后按角色/章节分块重读源文本，逐 label 核对原文，再行分析撰写。

## 步骤概览
1. **基础数据采集**：分批直读源 `.rpy` 文件（每批约 1,500–2,000 行），覆盖全部事件，输出到 `_tmp_digest/`。
2. **进度记录**：关键步骤留痕，为索引构建提供依据。
3. **零散内容处理**：分析中遇到的零散句子与句段集中收录，避免遗漏。
4. **汇总与筛选**：排除实现层细节，聚焦剧情与母题分析。
5. **文档生成**：按下述结构编排放出。

## 目录结构与产物
- **人物事件线/**：37 份角色深读文档（每份五部分结构：角色基本盘／love 线逐事件脉络／lust 线概貌／与主线元叙事咬合点／未解伏笔），正文直述剧情、行号回源；另有《人物事件线全梳理.md》横向汇总。
- **索引/**：35 份 `<角色>索引.md`，label 检索表与交叉引用全部外迁于此，正文不内嵌表格。
- **主线章节脚本精读.md**：主线章节（script → ch2script → chap3 → finalwarning → chap4 → chap4part2）的逐场景精读。
- **全文本梳理.md**：全量文本的纵向梳理。
- **系统层文本母题表.md**：`barrier / wall`、`cycle / loop / reset`、`code / creator` 等母题词汇的系统级归档，各文档引用时标注来源。
- **USER3与pareidolia源文分析.md**：专篇溯源。

## 强制约束
- **五段结构**：《人物事件线/<角色名>.md》必须完整呈现五部分分析主体；label 检索表不内嵌正文，统一外迁 `索引/<角色>索引.md`，正文末尾仅留一行指针。
- **正文纯论述**：不出现「详见《xxx.md》」式索引指引；表格、完整索引、交叉引用链路一律移至 `索引/` 子目录。
- **不做增补式写作**：新内容一律融入对应文档的既有结构，不设「补充/增量」类独立小节。
- **只写实际剧情**：好感度阶梯、电话/直播系统、天气联动等机制描述一律不入正文；引文标注 `文件.rpy:行号`。
